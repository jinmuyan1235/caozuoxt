# 实验一 Python 复现说明

所有自编实验程序统一使用 Python 3.12。主实验和并行数据采自 2026-11-17，Python CPU 补测及环境复测采自 2026-11-18，详见各 CSV 的实际时间和 PID。

在本目录打开 PowerShell，先安装并核对依赖。

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 -c "import sys,psutil,matplotlib; print(sys.version); print(psutil.__version__,matplotlib.__version__)"
```

主实验先做十点基线，再做带控制的十二周期采样。每次运行会产生新的 PID 和时间。

```powershell
py -3.12 exp1_process.py --mode baseline --points 10 --out baseline
py -3.12 exp1_process.py --points 12 --interval 0.5 --out repeat
```

Process Explorer 的历史对照使用 55 点、1 s 周期。重新运行时根据控制台显示的子 PID 核对三个时点，再记录截图时刻和最近的 CSV 样本，更新对照表。历史图中的 PID 24960 仅对应 2026-11-17 记录。

```powershell
py -3.12 exp1_process.py --mode crosscheck --skip-inventory --points 55 --interval 1 --out check
```

Python CPU 负载及采样程序直接启动当前解释器运行忙循环，不需要编译器。输出名称就是 taskmgr_cpu_trace.csv，不需要手动改名。

```powershell
py -3.12 辅助核对源码/tm_sample.py --seconds 360 --out python_check
```

采样期间，在任务管理器详细信息页按子 PID 定位，分别记录三个时点的 CPU 与工作集，并保留显示 PID 的截图。前五线程数核对时，需要同一窗口内重新枚举，以新快照为准。本次补测已完成。原始证据位于 数据/任务管理器补测，截图包括前五线程数及 CPU 三个时点。线程比较须按 PID 对齐，CPU 按截图附近的程序采样计算差值。

并行测量先检查当前电源计划，把括号前的 GUID 记下来。进入控制面板的电源选项，选择高性能后再次查看，确认当前计划确已切换。

```powershell
powercfg /getactivescheme
powercfg /list
```

也可在系统存在高性能计划时运行以下切换命令，检查返回结果，并在实验结束后以先前记录的 GUID 恢复。

```powershell
powercfg /setactive SCHEME_MIN
powercfg /getactivescheme
py -3.12 exp1_parallel.py --limit 1000000 --plan HighPerformance --out bench
powercfg /setactive <先前记录的电源计划GUID>
powercfg /getactivescheme
```

--plan 参数只写标签。并行 CPU 列是 count_primes 内部的计算 CPU 时间归一化值，墙钟包含进程池启动、通信和关闭；该 CPU 列没有计入全部额外 CPU 开销。每组 1、2、4、8 工作进程均重复三次并取中位数。

创建调用窗口是父进程看到的 Popen 调用耗时。first_code 是模块导入后 worker 中的 Python 埋点，无法据此单独测得纯就绪时间或内核单次上下文切换成本。

前五线程数核对可先做一次枚举，再按当次前五 PID 抓取邻近时刻快照。

```powershell
py -3.12 辅助核对源码/taskmgr_inventory.py --out current_processes.csv
py -3.12 辅助核对源码/taskmgr_inventory.py --pids 4 21424 7204 6216 3244 --out selected_processes.csv
```
上述 PID 仅示范 2026-11-18 的这组补测，复现时应替换为当次枚举的前五 PID。
